# 最近開啟

位於設定側欄「歷史記錄」下方，自動記錄 Windows 檔案總管前景視窗及作用中分頁瀏覽的實體資料夾，不需要使用搜尋。不記錄檔案、背景導覽、第三方檔案管理器、檔案對話方塊及虛擬位置。

預設啟用，保留 200 筆（1–5000），選單顯示 20 筆（1–100，且不超過保留筆數）。相同路徑只保留一筆，最近存取置頂，不按天數過期。關閉記錄後保留資料，停止新增及更新時間。

排除清單每行一個絕對目錄，支援環境變數及目錄選擇，包含子目錄。套用後也會刪除已有的相符記錄，不支援萬用字元。刪除及清空立即生效；其他選項按「套用」儲存。真正再次瀏覽後可以重新記錄。

快速導覽以「歷史記錄 → 分隔線 → 最近開啟」排列，支援逐層展開資料夾。級聯資料夾瀏覽器外掛提供獨立的顯示開關。

啟動時只擷取目前前景資料夾，事件約合併 200 毫秒，極短暫的中間目錄可能不收錄。記錄儲存於使用者資料目錄的 `recent-folders.json`，約合併一秒後原子儲存，正常退出時刷新。意外終止可能遺失尚未儲存的記錄；暫時離線的目錄保留資料但不顯示在選單中。
