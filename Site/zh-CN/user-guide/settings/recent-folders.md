# 最近打开

“最近打开”位于设置侧栏的“历史记录”下方，自动记录 Windows 资源管理器前台窗口、活动标签页中访问的真实文件夹。无需使用 Lertaro 搜索。文件、后台目录变化、第三方文件管理器、文件对话框和“此电脑”等虚拟位置不会记录。

- **记录文件夹访问**：默认开启。关闭后保留记录，停止新增及更新时间。
- **保存条数**：默认 200，范围 1–5000；超过容量时移除最旧的记录。
- **菜单条数**：默认 20，范围 1–100，且不能超过保存条数。
- **不记录这些目录**：每行填写一个绝对目录，可使用环境变量，也可点击“选择目录”。仅排除该目录本身，不包含其子目录；不支持通配符。点击“应用”后，也会移除已有的匹配记录。
- **搜索与清理**：支持按名称或路径搜索。单条删除和清空立即生效；其他设置通过“应用”保存。清空不会重置搜索历史，重新实际访问目录后可以再次记录。

快速导航中的排列为“历史记录 → 分隔线 → 最近打开”。目录支持逐层展开子目录，点击行为与其他级联目录相同。可在“设置 → 插件 → 级联文件夹浏览器”关闭“显示最近打开”，记录开关与显示开关互相独立。

同一路径只保留一条，最近访问置顶。切换到已有窗口或标签也算访问；重复窗口事件不会反复更新时间。事件约合并 200 毫秒，极短暂的中间目录可能不会收录。程序启动后采集当前前台目录，不扫描补录全部窗口。

记录保存于用户数据目录的 `recent-folders.json`，重启后保留，不按天数过期。目录暂时离线时不会永久删除记录，菜单展开时会跳过不可访问目录。后台约合并一秒的更新后原子保存，正常退出时刷新；意外终止可能丢失最后尚未保存的记录。
