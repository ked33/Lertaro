# 최근 연 폴더

설정의 기록 바로 아래에 표시됩니다. 전경 Windows 파일 탐색기의 활성 탭에서 방문한 실제 폴더를 검색과 별도로 기록합니다. 파일, 백그라운드 탐색, 다른 파일 관리자, 파일 대화상자 및 가상 위치는 기록하지 않습니다.

기본적으로 활성화되며 200개(1~5000)를 저장하고 메뉴에는 20개(1~100, 저장 개수 이하)를 표시합니다. 같은 경로는 하나로 합치고 최근 방문 순으로 정렬합니다. 날짜에 따른 만료는 없습니다. 비활성화하면 기존 기록은 유지하고 추가 및 시간 갱신을 중지합니다.

제외 목록은 줄마다 절대 경로 하나를 입력하며 환경 변수와 폴더 선택을 지원합니다. 지정한 폴더만 제외하며 하위 폴더는 제외하지 않습니다. 적용 시 일치하는 기존 기록을 삭제합니다. 와일드카드는 지원하지 않습니다. 삭제와 전체 삭제는 즉시 반영되며 나머지 설정은 적용 버튼으로 저장합니다. 실제로 다시 방문하면 다시 기록할 수 있습니다.

빠른 탐색에는 기록, 구분선, 최근 연 폴더 순서로 표시하며 하위 폴더를 단계별로 펼칠 수 있습니다. Folder Cascader의 표시 옵션은 기록 옵션과 독립적입니다.

시작할 때 현재 전경 폴더만 수집합니다. 이벤트를 약 200밀리초 동안 합치므로 매우 짧게 거친 폴더는 누락될 수 있습니다. `recent-folders.json`에 약 1초 단위로 안전하게 저장하고 정상 종료 시 남은 기록을 저장합니다. 비정상 종료하면 마지막 미저장 기록이 손실될 수 있습니다. 일시적으로 접근할 수 없는 폴더는 기록을 유지하되 메뉴에서 건너뜁니다.
