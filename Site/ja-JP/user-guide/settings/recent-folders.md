# 最近開いたフォルダー

設定の「履歴」の直下に表示されます。前面の Windows エクスプローラーのアクティブなタブで表示した実際のフォルダーを、検索とは独立して記録します。ファイル、バックグラウンドの移動、他社製ファイルマネージャー、ファイルダイアログ、仮想の場所は対象外です。

既定で有効です。保存件数は 200（1～5000）、メニュー件数は 20（1～100、保存件数以下）。同じパスは1件にまとめ、最近のアクセス順に並べます。日数による有効期限はありません。無効にしても既存の記録は残り、追加と日時更新が停止します。

除外は絶対パスを1行に1つ指定し、環境変数とフォルダー選択に対応します。サブフォルダーも除外し、適用時に一致する既存記録も削除します。ワイルドカードは使えません。削除と全消去はすぐに反映され、その他の設定は「適用」で保存します。再び実際に訪問すると再記録されます。

クイックナビゲーションでは「履歴 → 区切り線 → 最近開いたフォルダー」の順に表示し、サブフォルダーを階層的に展開できます。Folder Cascader の表示設定は記録設定と独立しています。

起動時は前面のフォルダーだけを取得します。イベントは約200ミリ秒にまとめるため、短時間の中間フォルダーは記録されない場合があります。`recent-folders.json` に約1秒分をまとめて安全に保存し、正常終了時に未保存分を書き込みます。異常終了では最後の未保存分を失う場合があります。一時的にアクセスできないフォルダーは保存したままメニューから除外します。
